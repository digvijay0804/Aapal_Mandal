# 🙏 Kranti Yuvak Ganesh Mandal

A modern, responsive public website for **Kranti Yuvak Ganesh Mandal**.

## 🌐 Website

The website is designed to provide information about the Ganesh Mandal, upcoming events, programs, activities, gallery, and contact details.

## ✨ Features

- 🏠 Modern Home Page
- 🙏 Ganesh Mandal Information
- 📅 Events & Programs
- 🖼️ Photo Gallery
- 📢 Announcements
- 📍 Contact & Location Information
- 📱 Fully Responsive Design
- 💻 Mobile & Desktop Friendly
- ⚡ Fast and Lightweight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Git & GitHub
